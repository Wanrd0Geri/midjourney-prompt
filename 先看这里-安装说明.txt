# Midjourney Prompt Skill 安装教程

适用于 Windows 10 / 11 与 Codex Desktop。

安装后，你可以在任意新任务中输入 `$midjourney-prompt`，让 Codex 把中文画面想法整理成可直接复制到 Midjourney 的英文提示词。当前默认固定 V8.2，明确要求时可使用 V8.1。

## 一、安装包里有什么

解压安装包后，应看到：

```text
midjourney-prompt-安装包/
├─ 安装教程.md
├─ 开始安装.bat
├─ install.ps1
└─ midjourney-prompt/
   ├─ SKILL.md
   ├─ agents/
   ├─ references/
   └─ scripts/
```

请不要单独移动或删除 `midjourney-prompt` 文件夹里面的文件，否则 Skill 可能无法读取本地提示词库。

## 二、推荐安装方法：一键安装

1. 下载并完整解压 ZIP 安装包，不要直接在压缩包预览窗口里运行文件。
2. 打开解压后的文件夹。
3. 最简单的方法是双击 `开始安装.bat`。
4. 如果双击没有运行，请在文件夹空白处按住 `Shift` 并点击鼠标右键，选择“在此处打开 PowerShell 窗口”或“在终端中打开”，然后运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\install.ps1"
```

5. 看到“安装成功”后，彻底退出并重新打开 Codex。

这条命令只对本次安装临时绕过 PowerShell 脚本限制，不会修改电脑的永久执行策略。

## 三、手动安装方法

如果不想运行脚本，也可以手动复制：

1. 复制整个 `midjourney-prompt` 文件夹。
2. 打开下面的目录：

```text
%USERPROFILE%\.codex\skills\
```

3. 将文件夹粘贴进去。
4. 最终必须形成下面的结构：

```text
C:\Users\你的用户名\.codex\skills\midjourney-prompt\SKILL.md
```

请特别注意：不要多套一层同名文件夹。错误示例：

```text
...\midjourney-prompt\midjourney-prompt\SKILL.md
```

如果 `.codex` 或 `skills` 文件夹没有显示，请在文件资源管理器中开启“显示隐藏的项目”，也可以直接把 `%USERPROFILE%\.codex\skills` 粘贴到地址栏后按回车。

## 四、验证是否安装成功

在 PowerShell 中运行：

```powershell
Test-Path "$env:USERPROFILE\.codex\skills\midjourney-prompt\SKILL.md"
```

返回 `True`，说明核心文件已经放到正确位置。

还可以检查本地提示词库：

```powershell
$manifest = Get-Content -Raw -Encoding UTF8 "$env:USERPROFILE\.codex\skills\midjourney-prompt\references\manifest.json" | ConvertFrom-Json
$manifest.totalPrompts
```

正常应显示：

```text
14583
```

这是跨分类去重后的唯一提示词 ID 数；分类文件合计为 21858 行，其中包含跨分类重复记录。

## 五、第一次使用

重启 Codex，新建一个任务，输入：

```text
$midjourney-prompt
一只橘猫坐在上海雨夜的霓虹招牌下面，电影感，小红书竖图。
```

默认会得到：

- 1 条主提示词；
- 2 条不同方向的变体；
- 简短的构图、风格和参数说明。

把英文提示词完整复制到 Midjourney 即可出图。这个 Skill 负责生成提示词，不会直接替你生成图片。

## 六、更新已有版本

如果电脑中已经存在同名 Skill，一键安装程序会主动停止，不会覆盖原文件。

更新时建议：

1. 彻底退出 Codex；
2. 到 `%USERPROFILE%\.codex\skills\` 中把原文件夹重命名为备份，例如 `midjourney-prompt-backup`；如果升级自旧版，也请处理 `midjourney-v8-1-prompt`，避免两个 Skill 同时触发；
3. 再运行新的 `install.ps1`；
4. 确认新版可用后，再自行处理旧备份。

## 七、常见问题

### 输入 Skill 名称后没有反应

- 确认已经彻底退出并重新打开 Codex；
- 确认文件路径没有多套一层文件夹；
- 确认调用名称完全一致：`$midjourney-prompt`。

### PowerShell 提示禁止运行脚本

不要直接双击脚本。请在安装包目录打开 PowerShell，并使用教程中的完整命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\install.ps1"
```

### 提示目标文件夹已经存在

说明电脑里已经安装过同名 Skill。先备份或重命名旧文件夹，再重新运行安装程序。

### Skill 能调用，但没有返回理想画面

尽量补充用途、主体、场景、风格和比例。例如：

```text
$midjourney-prompt
用途：小红书封面
主体：红色新中式长裙女性
场景：秋日下午的老建筑红墙
风格：东方电影感
比例：9:16
```
